# Citation and attribution status

This project is an expanded portfolio rebuild derived from graduate forecasting coursework. It is not a journal article, conference paper, or released software package.

Formal author, version, release date, repository URL, and license metadata remain owner decisions for a future release after the final Module 8B audit. Until then, refer to the project descriptively as:

> Seasonal Demand Forecasting — analytical demonstration and portfolio rebuild derived from graduate coursework.

This project does not claim authorship of professor-created prompts, course materials, or the unresolved historical dataset. Those materials are preserved separately and are not included in the intended public export.
